Здесь перечислены направления, которые рассматриваются к развитию. Сроки и обязательства по выпуску не обещаны.

## История разработки: Agent V1 → Agent V2

Первая версия Agent была написана на Node.js. Она работала, но возможности оркестрации, поддержки кода, производительности и сложности разработки ограничивали дальнейшее развитие. В Agent V2 runtime агента перенесли на Rust. После этого проект расширил сценарии Agent, управление контекстом и его компакцию, инструменты и функции самого приложения, например Rich Responses. Наглядные ответы — более поздняя функция приложения, а не особенность Rust.

## Текущие приоритеты

1. **Поддержка MCP** — изучить совместимость с внешними серверами инструментов и определить безопасные границы разрешений.
2. **Long-term Experience / Memory** — исследовать сохранение опыта между отдельными задачами. Существующие Task Notes, рабочая память и компакция контекста помогают текущей задаче, но не являются этой постоянной памятью.
3. **Упрощённый просмотр изменений** — менее приоритетное улучшение проверки предлагаемых правок.
4. **Режим нескольких агентов** — крупная архитектурная задача, связанная с координацией, общим состоянием, разрешениями и ресурсами.

## Экспериментальная идея

**Mobile Chat Remote** — возможное направление для изучения, но не утверждённая часть основной дорожной карты.
